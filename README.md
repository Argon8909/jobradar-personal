# JobRadar Personal

Персональный AI-ассистент для поиска и отбора вакансий на HeadHunter (hh.ru).

## Назначение

Локальное некоммерческое приложение для личного использования соискателем. Помогает находить вакансии, анализировать полные описания относительно редактируемого профессионального профиля и выбирать подходящие предложения.

## Планируемые возможности

- Поиск вакансий и получение их описаний через официальный HeadHunter API, в пределах предоставленного доступа.
- Сохранение вакансий, исключение дубликатов и учёт истории обработки.
- AI-анализ соответствия требованиям и объяснение причин рекомендации.
- Локальный интерфейс для просмотра и ручного выбора вакансий.
- Подготовка сопроводительных писем на основе подтверждённых сведений о соискателе.
- Отправка выбранных откликов **только после подтверждения пользователем**, если официальный API и права приложения позволяют это сделать.
- Обработка ошибок и ситуаций, требующих ручного действия.

## Предполагаемый стек

Python, SQLite, LLM API и простой локальный веб-интерфейс.

## Статус

Проект на стадии планирования. Интеграция с HeadHunter API, OAuth-авторизация и возможность отправки откликов ещё подлежат практической проверке. Рабочая реализация пока отсутствует.

## Принципы

Минимальная архитектура для одного пользователя; без SaaS-инфраструктуры. Не обходить CAPTCHA и ограничения платформы. Не выдумывать опыт или квалификацию соискателя.
